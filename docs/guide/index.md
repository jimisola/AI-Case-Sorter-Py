# AI Case Sorter — Qt UI Guide

A short guide to the Qt desktop client (launched with `--qt`), covering the
screens you use day to day. This is a proof-of-concept guide: it documents
two screens end to end so the same Markdown can be checked both on GitHub
and inside the app's own help viewer.

## Contents

- [Sort dashboard](sort.md) — the sidebar's main working screen: live camera
  preview, slot cards, sorting templates, and the Start/Stop/Manual-feed
  controls.
- [Settings](settings.md) — device and board configuration, including
  [Serial](settings.md#serial) and [Camera](settings.md#camera).

## How this guide works

Every page here is plain Markdown, rendered two ways from the same files:

- **On GitHub**, browsing straight to `docs/guide/`.
- **In the app**, through the help viewer (`F1`, or Help → User Guide),
  which opens the page for whatever screen you're on and can jump straight
  to a section — like [Settings → Serial](settings.md#serial).
